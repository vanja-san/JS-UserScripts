# Pinato

![Tampermonkey](https://img.shields.io/badge/Tampermonkey-✔-lightgreen?logo=tampermonkey) ![Violentmonkey](https://img.shields.io/badge/Violentmonkey-✔-lightgreen?logo=violentmonkey) ![Greasemonkey](https://img.shields.io/badge/Greasemonkey-✔-lightgreen?logo=greasemonkey)

> Открывает пины Pinterest во всплывающем модальном окне прямо на странице, без перехода на страницу пина.

*(скоро)*

## ✨ Возможности

- **Мгновенный просмотр** – клик по пину открывает его в красивом модальном окне.
- **Настоящий стиль Pinterest** – адаптивный дизайн, размытие (blur) и полупрозрачные панели, полностью соответствующие оригинальному интерфейсу.
- **Автоматическое извлечение данных** – скрипт находит название пина, описание и изображение в максимальном качестве.
- **Удобное управление**:
  - Кнопка закрытия `✕` в правом верхнем углу (появляется при наведении).
  - Нижняя информационная панель с заголовком, описанием и кнопкой **«Открыть на Pinterest»** (появляется при наведении).
  - Закрытие по клику на фон или по клавише `Esc`.
- **Адаптивность** – корректно отображается на мобильных устройствах (панели всегда видны).
- **Лёгкость** – не требует внешних зависимостей, работает только на Pinterest.

## 🚀 Установка

1. Установите менеджер юзерскриптов:
   - [Tampermonkey](https://www.tampermonkey.net/) (рекомендуется)
   - [Violentmonkey](https://violentmonkey.github.io/)
   - [Greasemonkey](https://www.greasespot.net/) (может потребоваться адаптация)

2. Нажмите на ссылку ниже, чтобы установить скрипт:  
   👉 **[Установить Pinterest Modal Viewer](https://raw.githubusercontent.com/vanja-san/JS-UserScripts/main/scripts/Pinato/pinato.user.js)**  

   Либо создайте новый скрипт вручную и скопируйте содержимое [этого файла](pinato.user.js).

## 🧑‍💻 Использование

1. Зайдите на любой сайт Pinterest (например, `ru.pinterest.com`).
2. Прокручивайте ленту и кликайте на любой пин.
3. Вместо перехода на страницу пина откроется модальное окно с изображением и информацией.
4. Для закрытия:
   - нажмите на затемнённый фон,
   - нажмите `Esc`,
   - кликните по кнопке `✕` в правом верхнем углу (появляется при наведении).

## 🛠 Технические детали

- **Язык:** JavaScript (ES6+)
- **API:** Используется только стандартный DOM API + `GM_addStyle` для инъекции стилей.
- **Совместимость:** Pinterest (все региональные домены).
- **Производительность:** Минимальное влияние, обработчик кликов работает только на ссылках, ведущих на `/pin/`.
