## Установка

```
node --test "scripts/Nexus Russian Localizer/tests"   # тесты логики
start "scripts\Nexus Russian Localizer\tests\dom-harness.html"   # тесты движка в браузере
```

## ✨ Особенности:
- **Один словарь — один источник правды**: `translations.js`, без дублирования в коде
- **Полностью синхронный движок**: ни IndexedDB, ни Web Worker, ни `await` в горячем пути
- **Поддержка Next.js**: перевод не сбрасывается при клиентской навигации без перезагрузки
- **Точная идемпотентность**: движок помнит исходный текст каждого узла, а не угадывает по кириллице
- **Без разрушения разметки**: переводятся текстовые узлы, а не `element.textContent`
- **Контекстные переводы**: переводы учитывают CSS-селектор элемента-владельца
- **Динамические правила**: даты, «5 minutes ago», «8.9k mods», размеры файлов
- **Правильная плюрализация**: 1 мод / 3 моды / 8.9k модов, числа разнесены по разным узлам
- **Склейка фраз**: «Recently » + `<span>Added</span>` -> «Недавно добавленные»
- **Контекст не теряется при SPA**: повторная попытка перевода при изменении окружения узла
- **Нет FOUC**: страница скрывается до первого перевода, страховка — 3 секунды
- **Переключатель**: меню «NRL: Включить / выключить» без удаления скрипта
- **Тесты**: 25 unit-тестов логики + браузерный харнесс движка, оба запускаются в CI

## Меню Tampermonkey / Violentmonkey

| Пункт | Действие |
| --- | --- |
| Включить / выключить | Переключает скрипт и перезагружает страницу |
| Перевести страницу заново | Полный проход по DOM |
| Статистика перевода | Таблица в консоли: узлы, атрибуты, фразы, кэш |
| Включить/выключить отладку | Подробный лог в консоли (перезагрузите страницу) |

## Структура проекта:
- `NRL.user.js` — метаданные, запуск, скрытие FOUC, меню
- `translations.js` — словарь и настройки перевода (единственный файл для правок)
- `modules/core.js` — правила, перевод DOM, MutationObserver, SPA-навигация
- `tests/nrl.test.js` — unit-тесты логики (`node --test`)
- `tests/dom-harness.html` — проверка движка в браузере

### Секции `translations.js`

| Секция | Назначение |
| --- | --- |
| `main` | Обычный словарь: текст -> перевод |
| `contextual` | Переводы по CSS-селектору владельца |
| `months` | Месяцы для дат (регистр не важен) |
| `datePrefixes` | «Published»/«Updated» -> «Опубликовано»/«Обновлено» |
| `units` | Считаемые существительные, три формы: `["мод", "моды", "модов"]` |
| `timeUnits` | Единицы времени для «N minutes ago» |
| `fileSizes` | `GB` -> `ГБ` |
| `suffixes` | Суффиксы масштаба. **Пустой объект = `8.9k` остаётся как есть.** Заполните `{ "k": "тыс." }`, чтобы переводить |
| `phraseInlineTags` | Теги, содержимое которых можно склеивать в фразу |
| `translatableAttributes` | Единственный список атрибутов (он же `attributeFilter` для MutationObserver) |

## Порядок перевода текстового узла

1. Плюрализация по числу в соседних узлах
2. Контекстные правила (`element.matches`)
3. Общий словарь
4. Динамические правила (даты, время, числа, размеры)
5. Суффиксы масштаба
6. Склейка соседних узлов в фразу

## Что не переводится

- `.mod-name`, `.description`, `.user-content`, `blockquote` и прочие из `CONFIG.IGNORED_SELECTORS`
- Классы `no-translate`, `notranslate`, `ignore-translation`, `code`, `pre`
- Стандартный HTML-флаг `<span translate="no">`
- Теги `script`, `style`, `textarea`, `svg` и прочие из `CONFIG.IGNORED_TAGS`
- Текст, уже переведённый ранее: узел помнит исходную строку и не трогается повторно
- Исключение: класс `sr-only` переводится всегда — это контент для скринридеров
