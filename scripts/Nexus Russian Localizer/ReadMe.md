```
node --test "scripts/Nexus Russian Localizer/tests"          # 54 unit-теста
start "scripts\Nexus Russian Localizer\tests\dom-harness.html"   # 39 проверок движка в браузере
```

## ✨ Особенности
- **Один словарь — один источник правды**: `translations.js`, без дублирования в коде
- **Полностью синхронный движок**: ни IndexedDB, ни Web Worker, ни `await` в горячем пути
- **Поддержка Next.js**: перевод не сбрасывается при клиентской навигации без перезагрузки
- **Обратимый перевод**: движок помнит исходный текст каждого узла и может вернуть английский
- **Без разрушения разметки**: переводятся текстовые узлы, а не `element.textContent`
- **Словари по страницам**: маршрутизация URL → свой набор переводов и игнор-правил
- **Учёт непереведённых строк**: показывает реальное покрытие словаря, экспорт в JSON
- **Граница ошибок**: сбойный участок страницы не роняет весь перевод
- **Контекстные переводы**: переводы учитывают CSS-селектор элемента-владельца
- **Динамические правила**: даты, «5 minutes ago», «8.9k mods», размеры файлов
- **Правильная плюрализация**: 1 мод / 3 моды / 8.9k модов, числа разнесены по разным узлам
- **Склейка фраз**: «Recently » + `<span>added</span>` → «Недавно добавлены»
- **Shadow DOM**: заходит в открытые shadow root веб-компонентов
- **Перевод заголовка вкладки** через `titleRules`
- **Нет FOUC**: страница скрывается до первого перевода, страховка — 3 секунды
- **Откат по требованию**: пункт меню возвращает английский оригинал на странице
- **Тесты**: 54 unit-теста + браузерный харнесс, всё гоняется в CI

## Меню Tampermonkey / Violentmonkey

| Пункт | Действие |
| --- | --- |
| Перевести страницу заново | Полный проход по DOM |
| Вернуть английский оригинал | Откат всех переводов на странице |
| Статистика перевода | Таблица в консоли: узлы, атрибуты, фразы, покрытие |
| Включить/выключить учёт непереведённых | Сбор непереведённых строк в JSON |
| Включить/выключить отладку | Подробный лог в консоли |

Сам скрипт включается и выключается штатными средствами Tampermonkey
(панель скриптов → переключатель) — собственного переключателя нет.
Чтобы вернуть перевод после «Вернуть английский оригинал», обновите страницу.

## Структура проекта
- `NRL.user.js` — метаданные, запуск, скрытие FOUC, меню
- `translations.js` — словарь, маршруты страниц, правила (единственный файл для правок)
- `modules/core.js` — движок: правила, DOM, MutationObserver, SPA-навигация, учёт непереведённых
- `tests/nrl.test.js` — unit-тесты логики, хранилища и учёта непереведённых
- `tests/routing.test.js` — регрессии маршрутизации словаря
- `tests/dom-harness.html` — проверка движка в браузере
- `script/bump-version.js` — автобump версии словаря (запускается в CI)

## Порядок перевода текстового узла

1. Плюрализация по числу в соседних узлах
2. Контекстные правила (`element.matches`)
3. Словарь страницы → универсальный `main`
4. Регулярки страницы
5. Динамические правила (даты, время, числа, размеры)
6. Суффиксы масштаба
7. Склейка соседних узлов в фразу

## Версионирование

Формат: `<версия движка>-<метка словаря>`, например `3.1.0-20261018-1608`.

- **Версию движка** меняете вы, руками, в `NRL.user.js`.
- **Метку словаря** проставляет CI (`script/bump-version.js`) по времени последнего коммита `translations.js`, и она же попадает в `?v=` у обоих `@require`.

Зачем: Tampermonkey кэширует `@require` по URL. Без `?v=` новый словарь не доезжал бы до пользователей до ручного бампа версии. Метка включает время, а не только дату — иначе две правки словаря в один день дали бы одну версию, и вторая не доехала бы.

## Что не переводится
- `.mod-name`, `.description`, `.user-content`, `blockquote` и прочие из `CONFIG.IGNORED_SELECTORS`
- Классы `no-translate`, `notranslate`, `ignore-translation`, `code`, `pre`
- Стандартный HTML-флаг `<span translate="no">`
- Теги `script`, `style`, `textarea`, `svg` и прочие из `CONFIG.IGNORED_TAGS`
- Текст, уже переведённый ранее: узел помнит исходную строку и не трогается повторно
- Исключение: класс `sr-only` переводится всегда — это контент для скринридеров

## Секции `translations.js`

| Секция | Назначение |
| --- | --- |
| `conf.routes` | Маршруты URL → `pageType`. Порядок важен: специфичные раньше общих |
| `conf.ignoreSelectorPage` | Игнор-селекторы по страницам, `'*'` добавляется ко всем |
| `conf.ignoreMutationSelectorPage` | Элементы, мутации которых игнорируются |
| `conf.characterDataIgnorePage` | Страницы без наблюдения `characterData` (экономит CPU) |
| `pageDictionaries` | Переводы и регулярки по `pageType`. Перекрывают `main` |
| `titleRules` | Правила для `document.title` |
| `main` | Универсальный словарь: текст → перевод |
| `contextual` | Переводы по CSS-селектору владельца |
| `months` | Месяцы для дат (регистр не важен) |
| `datePrefixes` | «Published»/«Updated» → «Опубликовано»/«Обновлено» |
| `units` | Считаемые существительные, три формы: `["мод", "моды", "модов"]` |
| `timeUnits` | Единицы времени для «N minutes ago» |
| `fileSizes` | `GB` → `ГБ` |
| `suffixes` | Суффиксы масштаба. **Пустой объект = `8.9k` остаётся как есть.** Заполните `{ "k": "тыс." }` |
| `phraseInlineTags` | Теги, содержимое которых можно склеивать в фразу |
| `missedTerms` | Лимиты учёта непереведённых строк |
| `translatableAttributes` | Единственный список атрибутов (он же `attributeFilter` для MutationObserver) |
