## ✨ Особенности:
- **Модульная архитектура**: Код разделен на логические модули для лучшей поддержки
- **Производительность**: Используется кэширование в IndexedDB и памяти для ускорения работы
- **Контекстные переводы**: Переводы учитывают контекст элемента (тег, классы и т.д.)
- **Динамические шаблоны**: Поддерживаются регулярные выражения для перевода динамического контента (даты, количественные значения и т.д.)
- **Форматирование дат**: Специальная обработка строк с датами, например 'Published 10 окт 2025' → 'Опубликовано 10 окт 2025'
- **Мгновенный перевод подсказок**: Всплывающие подсказки (tooltips) переводятся сразу при наведении, без мигания
- **Поддержка элементов доступности**: Элементы с классами вроде 'sr-only' теперь также переводятся для улучшения доступности
- **Обработка элементов времени**: Теги `<time>` с датами и временем теперь корректно переводятся, включая форматы вроде '1 hour ago' и '15 Nov 2025'
- **Поддержка ARIA-подсказок**: Элементы с атрибутом `aria-describedby` теперь также обрабатываются для перевода всплывающих подсказок
- **Улучшенная производительность**: Сокращены задержки и оптимизированы алгоритмы для более быстрого перевода элементов, особенно дат и времени
- **Оптимизация DOM**: Эффективная обработка узлов с минимальными обращениями к DOM
- **Поддержка атрибутов**: Переводит текстовые атрибуты элементов (title, placeholder и др.)

## Структура проекта:
- `NRL.user.js` - основной скрипт
- `translations.js` - словарь переводов
- `ReadMe.md` - документация
- `modules/`
  - `config.js` - настройки (включая IGNORED_SELECTORS для названий/описаний модов)
  - `context-matcher.js` - контекстные правила перевода
  - `date-formatter.js` - форматирование строк с датами
  - `helpers.js` - совместимость (обёртки для PluralizationEngine)
  - `lru-cache.js` - LRU-кэш в памяти и управление кэшами
  - `pluralization.js` - движок плюрализации (суффиксы k/m/b/t, склонение слов, шаблоны)
  - `translation-cache.js` - кэш переводов (IndexedDB + Web Worker + автоинвалидация по хешу)
  - `translation-engine.js` - движок перевода (обработка DOM, атрибутов, MutationObserver)
